Our adapter follows the official dextools-io/integration-sdk HTTP schema
at commit a868b1aed7d31c835b351c3cb7d39cc5bc5e34b1. It provides latest-block,
block, asset, exchange, pair and events. It exposes real creation/buy/sell
events using block-global log indexes, transaction senders and decimal-string
amounts. Data is bounded by the RPC's finalized block, so new activity waits
for finalization. Inclusive event requests support up to 256 blocks.

Example curve token: 0x82e2b12864e04488f6a6a2602b30b11bb53cba91 (TEST).
The pair ID is the token address, identifying a curve inside the factory;
it is not a standalone Uniswap pair contract. Asset0 is the token and asset1
is RWI. ETH trades route through RWI. The TEST creation, actual buys and
sells have been checked against receipts and current contract accounting.
